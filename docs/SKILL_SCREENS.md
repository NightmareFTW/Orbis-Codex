# Skills to read from the game, in order

*Generated 2026-10-18 by `e7 kit audit` (391 heroes, epic7db has 382 pages) and the RTA tier list of epic7db; run `e7 skills todo` in the program for the live list, which also counts what is already read.*

## How (no screenshots)

1. `Orbis.cmd`, open **Dev tools > Skill reader**, press **Start reading** (or `e7 skills watch`).
2. In the game open the hero (its own screen, with the name large at the top left: the program reads and remembers the name there, so open it and wait a second) and **hold each of its three skill icons for about two seconds**. The badge on the game says `Read: <hero>` for each. Nothing is pressed or clicked for you: the program only looks at the screen.
3. When you want me to have it: **Export file** (or **Copy export**) on the same page and send me the text (a few hundred KB for the whole list). The table shows who is still missing; the heroes met in your Arena come first.

A hero is complete after three skills. The popups also show the description of every effect they name (Offering, Venom, Fear, ...), so a mechanic is learned once for everybody who has it.

## D. Fights (the only thing a popup cannot give)

The Battle Results screen after a fight (all its tabs) with the chance the program showed. **Four or five fights are enough to start**: pick ones where the program was confident and the result was a surprise or a close call, and a few it got right. For each: the Victory/Defeat screen and every tab of Battle Results (damage and recovery of both teams; the damage taken and the other tab if there is one). The Victory / Defeat and the chance shown are logged by the Arena watch by itself since SPEC D93 (`e7 arena results`), so **only the Battle Results numbers** need to be sent: screenshots, or just the numbers typed.

## E. What no screen gives

* The opponent's gear and stats (the game never shows them): the program uses Stove's profiles and, since this survey, the Fribbels hero-library averages that epic7db shows for every hero.
* How the game AI chooses a skill or a target: only recorded fights tell (a screen recording of the first turns of one fight, even 20 MB, is enough).
