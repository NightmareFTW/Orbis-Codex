# Art that comes with the program (TEMPORARY, public)

The skill icons the Skill reader cuts from the game's popups (`skills/<hero code>-<skill>.png`) are kept here so that
every PC that runs the program has them (SPEC D135). They are the game's art, in a public repository: **before the
first public release they move to a synchronised folder or a private repository** (see "Before the release" in
`CLAUDE.md`). Do not add anything else here.
